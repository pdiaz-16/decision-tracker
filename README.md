# Decision Tracker

A personal decision logging app built with Laravel. Track your decisions, set follow-up reminders, and rate outcomes over time.

## Features (planned)

- Log decisions with context and reasoning
- Set follow-up reminders to review decisions
- Rate outcomes and reflect on the result
- Decision history and personal insights

## Tech Stack

- **Backend:** Laravel (PHP)
- **Database:** MySQL
- **Frontend:** Inertia.js + Vue 3
- **Deployment:** Hostinger (Business plan, SSH)
- **Local dev:** Docker
